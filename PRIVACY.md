# Privacy Policy

Second Brain is a personal, single-user assistant run by its author for their own use.

- It requests read-only access to the author's Google Calendar (`calendar.readonly`).
- Calendar data is used only to answer the author's questions and to time reminders.
- No data is sold, shared with third parties, or used for advertising.
- The OAuth token is stored only on the author's own server and can be revoked at any time
  at https://myaccount.google.com/permissions.
